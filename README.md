# 台球计分助手 · 微信小程序

在微信开发者工具中打开本项目，使用项目现有的登录和 API 配置运行。开发版连接 `http://127.0.0.1:8080/api`。

## 斯诺克

- 首页选择斯诺克，添加两位球员，可配置 1–35 的奇数局赛制和 1–15 颗红球，预览理论单杆满分。
- 计分按现有后端快照显示红彩交替、清彩顺序、剩余红球、单杆、领先分和台面剩余分。平分清台后支持重置黑球。
- 犯规给对手加 4–7 分，可填写离台红球数、要求犯规者继续；换人结束单杆，撤销恢复服务端上一笔完整状态。
- 每局手动结算或认输，达到目标胜局后进入详情；认输保留实际比分，记录中显示整场胜局与逐局比分。
- 旧局缺少 `_snooker` 台面状态时继续手动记分；下一局由后端启用台面规则。自由球、多红球同杆等特殊裁判场景与当前 Web 实现一致，暂不自动处理。
- 请求失败后需刷新确认最新比分再继续，避免不确定请求被重复记分。

复用现有 `/score/sync`、`/score/undo`、`/match/round/next` 接口。结算提交当前 `round`，认输额外提交 `conceding_player_id`；服务端负责所有计分和结算规则。

## 验证

```sh
npm ci
npm run typecheck
npm test
npm run test:templates
```

`typecheck` 检查应用代码，跳过项目内旧版微信声明库的泛型约束错误。`npm test` 使用隔离的微信 API 环境，执行真实页面方法与请求封装，模拟服务端返回，覆盖配置校验、计分、犯规、换人、撤销、结算、断网和异常响应。

`test:templates` 使用本机微信开发者工具自带的 WXML/WXSS 编译器，编译全部模板和样式，验证页面注册、生成节点和事件绑定。默认使用 macOS `/Applications/wechatwebdevtools.app`，可通过 `WECHAT_COMPILER_DIR` 指定包含 `wcc`、`wcsc` 的目录。

模拟器或真机验收：创建一局赛，配置 1 颗红球，依次记录红、黑、黄、绿、棕、蓝、粉、黑，检查总分 35、剩余分 0；撤销后恢复黑球，重新记入并结算。再检查犯规离台红球、要求继续击球、刷新恢复和认输后的逐局成绩。模板编译与 API 模拟测试不替代真实微信运行环境验收。
